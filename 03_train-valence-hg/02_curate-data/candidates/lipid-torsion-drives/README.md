# Lipid torsion-drive candidates

This folder contains only the 103 records from `OpenFF Lipid Torsion Drives
v4.0` (76 records) and `v4.1` (27 records). The driven torsion is highlighted
in red in the PDF and PNG catalogs. The CSV identifies the source dataset for
every record and includes the QCArchive ID, assigned parameter, SMIRKS, driven
indices and elements, molecular formula, size, and SMILES.
